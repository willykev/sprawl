Fixes from a full code and security review of Sprawl 0.1.0.

- **Safety:** board files are only ever shown as text and never fetch
  anything from the network; only pictures are taken in as pictures;
  command output cannot drive the terminal; an item holds 10,000
  characters at most.
- **Saving:** work in progress is saved, including text being typed and
  things being dragged. Changes from `sprawl` commands, agents or another
  window are merged instead of written over. A board that could not be
  read opens read only and is never written over.
- **GPU:** the stroke being drawn counts toward each frame's budget, and
  `--probe` and `--bench` keep to what is known to be safe.
- **Canvas, exports and commands:** big selections stay fast, paste takes
  what it can, exports crop nothing, pen corners stay sharp, and
  everything follows a theme switch.

See `CHANGELOG.md` for the full list.

### Install

Download the `sprawl-0.1.1-1-aarch64.pkg.tar.*` package below for an ARM64
Arch/Omarchy system and install it with `sudo pacman -U <package-file>`.
The package is unsigned; `SHA256SUMS` records the release file checksums.

For Intel/AMD (`x86_64`), build from source on Arch/Omarchy:

```sh
git clone --branch v0.1.1 https://github.com/willykev/sprawl.git
cd sprawl
bin/install
```

The attached `PKGBUILD` also builds from the versioned source archive and
checks its SHA-256 hash. Run `makepkg -si` in a folder containing that recipe.
See the README for build dependencies.

### Scope

Boards stay on this machine. Device sync and live collaboration are not
included. The interface is currently in English.
