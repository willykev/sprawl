First public release of Sprawl for Omarchy.

Arrange notes, text, pictures, shapes, and sketches on an infinite canvas.
Includes attached connectors, frames, grouping, undo/redo, automatic saves,
PNG/SVG/PDF export, and a command-line interface.

### Install

Download the `sprawl-0.1.0-1-aarch64.pkg.tar.*` package below for an ARM64
Arch/Omarchy system and install it with `sudo pacman -U <package-file>`.
The package is unsigned; `SHA256SUMS` records the release file checksums.

For Intel/AMD (`x86_64`), build from source on Arch/Omarchy:

```sh
git clone --branch v0.1.0 https://github.com/willykev/sprawl.git
cd sprawl
bin/install
```

The attached `PKGBUILD` also builds from the versioned source archive and
checks its SHA-256 hash. Run `makepkg -si` in a folder containing that recipe.
See the README for build dependencies.

### Scope

Boards stay on this machine. Device sync and live collaboration are not
included. The interface is currently in English.
