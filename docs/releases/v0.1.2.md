A new README and a fuller example. Sprawl itself is unchanged from 0.1.1.

- **README:** pictures of Sprawl at work (a whole board, lines following a
  shape as it moves, the pen, the board switcher, one board in four
  themes), a short tour, measured performance, and how to update and
  remove Sprawl.
- **Example:** the weekend-trip board gains a dashed connector and a pen
  sketch. Open it with `sprawl open examples/weekend-trip`.
- **For contributors:** `bin/screenshots` redraws the README's pictures
  from the example board, off screen.

See `CHANGELOG.md` for the full list.

### Install

Download the `sprawl-0.1.2-1-aarch64.pkg.tar.*` package below for an ARM64
Arch/Omarchy system and install it with
`sudo pacman -U sprawl-0.1.2-1-aarch64.pkg.tar.*`. The package is unsigned;
`SHA256SUMS` records the release file checksums.

For Intel/AMD (`x86_64`), build from source on Arch/Omarchy:

```sh
git clone --branch v0.1.2 https://github.com/willykev/sprawl.git
cd sprawl
bin/install
```

The attached `PKGBUILD` also builds from the versioned source archive and
checks its SHA-256 hash. Run `makepkg -si` in a folder containing that recipe.
See the README for build dependencies.

### Scope

Boards stay on this machine. Device sync and live collaboration are not
included. The interface is currently in English.
